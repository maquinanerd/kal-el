# 05 — Calibration Screen

## Objetivo

Antes de produzir dezenas de telas, criar **uma única tela laboratório** no Claude Design que prove que a identidade visual foi reconstruída corretamente.

## A tela deve conter

- Full sidebar.
- Compact sidebar variant.
- Topbar.
- Breadcrumb.
- Page title.
- Primary + secondary buttons.
- Input, search, select, checkbox, radio e switch.
- Tabs/segmented control.
- KPI card.
- Generic card.
- Dense table com avatar, status e kebab.
- Pagination.
- Dropdown/context menu aberto.
- Account switcher aberto.
- Modal aberto em variante separada.
- Editor surface com inline toolbar.
- Contextual inspector.
- Toast/alert.
- Empty state.
- Light e dark.
- Desktop e mobile.

## Gates

Não avançar para Kal El nem Commerce Wayne enquanto houver P0/P1 em:

- font family/metrics;
- type scale;
- border contrast;
- radius;
- sidebar width;
- control height;
- row height;
- whitespace/density;
- overlay style;
- menu sizing;
- dark surfaces.

## Meta

Ao colocar a calibration screen ao lado dos screenshots, deve haver sensação clara de mesma família visual sem depender do logo ou da cor de accent.
