# Editor UX Specification

The editor must feel like a document editor, not like a database form or exposed block builder.

Required: natural paragraphs, contextual inline toolbar, slash commands, drag/drop/paste images, media library, safe URL embeds including YouTube, native galleries, H2-H4 body headings with article title as normal H1, links/lists/quotes/tables, constrained text highlights/colors through design tokens, featured image with crop/focal metadata, captions/credits/alt text, autosave, draft recovery, revision history/diff, target-site preview, document inspector, distraction-free mode.

Initial structured article variants: News/article, Review, List, Video article, Audio/podcast article.

Do not permit arbitrary executable HTML/JS. Store a versioned structured document schema rendered by trusted frontend components.
