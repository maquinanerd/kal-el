# Product Vision

Kal El is a central editorial operating system. Editors and automated pipelines create content once, associate it with a site and structured entities, preview it, publish it, and distribute it through stable APIs and events.

Core jobs: human writing/editing, automated ingestion, editorial workflow, structured content, media, editorial SEO, preview/publication, stable delivery, entity/taxonomy relationships, revisions/scheduling/auditability, and future distribution integrations.

Explicit v1 non-goals: Shopify replacement, generic page builder, WordPress plugin compatibility, arbitrary PHP, arbitrary executable HTML/JS in bodies, forced frontend framework, full SaaS billing/self-service.
